# screen-state-owned-jobs-skill v1.0.0 Release Notes

## Release Type

WorkBuddy / ChatGPT Skill compatible release package.

## Installation

Recommended installation:

1. Open GitHub Releases.
2. Download `screen-state-owned-jobs-skill-v1.0.0.zip`.
3. Do not extract the archive.
4. Import the ZIP file directly into the Skill manager.

## Package Structure

The release package must expose `SKILL.md` at the first directory level:

```text
SKILL.md
agents/
assets/
references/
scripts/
```

## Major Features

- Dynamic resume-driven candidate profile generation.
- No hard-coded candidate information.
- Resume parsing and validation workflow.
- Support for all organization types contained in the recruitment table.
- Priority identification of no-written-test opportunities.
- Fixed six-sheet Excel output specification.
- Evidence-based matching between resume information and job requirements.

## Compatibility

Supported workflow:

- WorkBuddy Skill import.
- ChatGPT Skill import.
- Codex-based execution workflows.

## Security Notes

The release package contains only Skill logic and templates.

It must not include:

- Personal resumes.
- Contact information.
- Generated recruitment reports.
- Local cache files.
